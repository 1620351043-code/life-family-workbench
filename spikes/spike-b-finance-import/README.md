# Spike B：多来源账单导入、表头探测与去重关联

## 运行

```bash
python3 test_import_spike.py
python3 import_spike.py
python3 real_bill_replay.py /Users/wrt/Downloads/账单
```

本 Spike 使用不含真实个人信息的合成 CSV，覆盖：

- 前置说明行，表头不在第一行。
- 银行、支付宝和微信不同字段名的映射。
- 金额符号和收支方向的规范化。
- 同一银行文件重复导出后的幂等识别。
- 银行账单与支付平台账单的跨来源候选关联。
- 银行记录作为资金锚点，支付平台记录保留为详细来源。

## 当前边界

这不是对真实银行/支付平台导出格式的兼容承诺。进入产品实现前，需要补充用户提供的脱敏样本，尤其是 XLSX 多 Sheet、PDF、ZIP、多行表头、合并单元格、退款、转账和同日多笔同额交易。

`real_bill_replay.py` 用于本地重放用户提供的 CSV/XLS/XLSX 文件。它只输出文件哈希前缀、工作表、表头行、字段映射、记录数量、去重组数量和关联数量，不输出商户、账号、金额、备注或订单号。
