# Life 财务与 PRD 差距复审报告 v0.2

复审时间：2026-08-25

基线报告：`outputs/Life-财务与PRD全量自检报告-v0.1.md`

## 1. 复审结论

本轮针对基线报告中“财务首页口径与趋势交互”的改进已经完成并通过验证：净资产、账户余额、待处理项、预算异常、趋势周期、图例显隐和实物资产成本指标切换均已进入真实 PostgreSQL 查询和移动端 React 页面。

当前结论分为两层：

- **本轮财务首页改进：达标。** 数据、API 契约、交互和窄屏 UX 均有验证证据。
- **财务全量 PRD / 生产发布：仍未达标。** 正式导出、原始账单生命周期/COS、生产 AI 连接与记忆隔离、趋势自定义范围和 HowToCook 仍未完成。

## 2. 差距闭环状态

| 基线差距 | 复审状态 | 实施结果 |
|---|---|---|
| 首页缺少净资产 | 已解决 | 账面净资产 = 当前 CNY 活跃账户余额 + 持有实物资产净现金成本，并提供摘要入口 |
| 首页缺少账户余额 | 已解决 | 从 `financial_account`、确认分录实时计算，摘要卡进入账户与预算 Sheet |
| 首页缺少待处理项 | 已解决 | 识别表头、映射、标准化、关联审核和待确认批次，入口直接打开导入向导 |
| 首页缺少异常提示 | 已解决 | 预算达到/超过额度显示预算超支提示，并下钻到预算账单 |
| 趋势只有日粒度 | 已解决 | 支持日、周、月、季；周期改变后由 PostgreSQL 重新聚合，数据点引用精确到周期范围 |
| 图例不可交互 | 已解决 | 收入、支出、净现金流图例可显隐，显隐不改变后端数据 |
| 资产趋势指标固定 | 已解决 | 支持总成本、净现金、购买、维护、回收指标切换，并保留资产事件下钻 |
| 趋势自定义日期范围 | 部分解决 | 当前支持上/下月与日/周/月/季；自定义起止日期控件尚未进入本轮 |
| 正式导出与导出审计 | 未解决 | `can_export` 已有授权位，导出 API 尚未实现 |
| 原始账单 365 天清理 | 未解决 | 批次保留日期已写入，清理 worker、提示、审计和 COS 生命周期尚未完成 |
| 腾讯云 COS 私有桶 | 未解决 | 当前仍为本地/内存对象存储开发实现 |
| 家庭独立生产 AI API/记忆 | 未解决 | 当前为 `deterministic-finance-v1` 开发 Provider，生产密钥引用和记忆文件尚未接入 |
| HowToCook 全链路 | 未解决 | 不属于本轮财务切片，仍待单独推进 |

新增/补强的 PostgreSQL 断言包括：

- 5 张摘要卡的键和值：净资产、账户余额、收入、支出、净现金流。
- 日趋势 31 个点、周趋势 5 个点，以及点级 `granularity` 下钻引用。
- 待处理导入和预算超支同时出现时，`attention_items` 返回正确的两个告警项。
- 资产事件趋势按周期聚合，空周期不伪造资产成本点。

## 4. 移动端 UX 验证

真实页面验证结果：

- 430×932：`scrollWidth=430`、`clientWidth=430`、窄按钮数为 0。
- 320×900：`scrollWidth=320`、`clientWidth=320`、窄按钮数为 0。
- 摘要卡“账户余额”打开账户与预算 Sheet；“净资产”打开资产与成本 Sheet。
- 趋势“周”切换后页面显示“按周展示”，并返回 5 个趋势点。
- 图例点击后对应系列变为 `inactive`，图表点同步隐藏。
- 资产指标切换到“维护”后页面显示“按周查看维护”。
- 趋势周期、资产指标和图例按钮均统一为至少 44×44pt，继续遵守液态玻璃/iOS 移动交互规范。
