# Life P0-C「实物资产与成本趋势」垂直切片卡 v0.1

状态：已完成，进入 P0-D 权限与审计扩展

更新时间：2026-08-25

关联 PRD：`outputs/Life-家庭生活工作台-PRD-v0.10.md` 第 5.3.3、5.3.6、7.4、8.4、9.1、10.3、12.2、14.3 节

## 1. 切片目标

让家庭成员在移动端登记实物资产、记录完整成本轨迹，并从首页成本趋势进入资产事件明细：

```text
资产列表 → 资产详情 → 新增购买/维修/耗材/升级事件
                     → 可选关联已确认账单
                     → 出售/处置后进入终止状态
                     → 更新累计成本、回收金额、净现金成本和首页趋势
```

## 2. 数据与业务规则

- `physical_asset` 是家庭资产主记录，`asset_event` 是不可通过普通列表删除的成本/回收事件。
- 事件类型覆盖购买、维修、耗材、升级、转让、出售和处置。
- 事件金额和回收金额使用定点金额字符串；非出售事件的回收金额不能大于事件金额。
- 事件可以关联当前家庭内已确认的 `ledger_transaction`；关联只建立来源关系，不重复扣减账户余额。
- 资产累计成本为事件金额之和，回收为回收金额之和，净现金成本为两者差值。
- 转让、出售、处置会把资产置为终止状态；终止资产保留历史事件，但禁止继续新增事件。
- 新增、编辑资产和新增事件执行家庭上下文、财务写权限校验并写入 `audit_log`。
- 首页资产成本趋势继续读取统一 `asset_event`，不引入第二份成本数据；趋势点和容器继续生成 `drilldown_ref`。

## 3. API 契约

| 方法 | 路径 | 目的 |
|---|---|---|
| `GET` | `/api/finance/assets` | 获取资产列表及累计成本 |
| `POST` | `/api/finance/assets` | 新增资产 |
| `GET` | `/api/finance/assets/{assetId}` | 查看资产详情和事件轨迹 |
| `PATCH` | `/api/finance/assets/{assetId}` | 编辑资产名称和类型 |
| `POST` | `/api/finance/assets/{assetId}/events` | 新增成本/回收事件 |

## 4. 移动端 UI/UX 验收标准

- 财务首页提供“资产”二级入口，与“账户与预算”保持同层级但不抢占新增记账主按钮。
- 资产列表使用 Bottom Sheet，展示名称、类型、持有状态、事件数量和净成本；空态给出明确的登记入口。
- 资产详情先显示累计成本、已回收、净现金成本，再显示状态、最近事件和事件轨迹。
- 新增事件表单将事件类型、时间、金额、回收金额和可选账单关联分组；保存后回到详情并刷新首页趋势。
- 出售/处置的终止语义在表单内提前说明；终止后不再展示“新增事件”按钮。
- 事件关联账单明确说明“不会重复扣款”，避免用户把来源关联误解为再次记账。
- 430×932 与 320×900 下 Sheet 内部可滚动，无横向溢出；按钮、选择器、输入框和关闭入口不小于 44×44pt。
- 资产事件错误在当前编辑器内展示，已填写内容保留；网络重试不会清空表单。

## 6. 后置增强

- 资产事件的用户发起撤销/修正入口，需要在权限审计切片中统一设计版本校验和反向审计。
- 资产按资产、月份、季度和生命周期切换，以及累计成本线的多指标显示，需要在财务详情扩展切片中补齐。
- 专业会计折旧和税务折旧不属于 V1.0。
