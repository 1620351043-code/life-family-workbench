# Life 财务账单导入与关联审核垂直切片卡 v0.1

更新时间：2026-08-25
状态：解析 worker、真实写入、关联审核和移动端提交已闭环；腾讯云 COS 适配后置；统一 UI 美化待收口

## 1. 切片目标

在移动端完成“选择账单文件 → 识别非首行表头 → 确认字段映射 → 查看跨来源关联候选 → 用户确认 → 生成统一账本”的真实闭环。

本切片服务于财务 V1 的核心约束：同一消费可能同时出现在银行、支付宝、微信或记账 App 中，正式账本只计一次，同时保留支付平台更详细的来源记录。

## 2. 已确认的样本回放证据

本地脱敏回放使用用户提供的四份账单文件。报告仅输出文件哈希前缀、结构和数量，不输出商户、账号、备注、订单号或金额。

| 来源 | 文件形态 | 识别表头 | 解析记录 | 同源去重后 |
|---|---|---:|---:|---:|
| 银行 | `.xls` | 第 4 行 | 547 | 547 |
| 微信 | `.xlsx` | 第 18 行 | 367 | 367 |
| 支付宝 | `.csv` | 第 24 行 | 420 | 420 |
| 记账 App | `.xls`，3 个 Sheet | 第 1 行；2 个空 Sheet | 5 | 5 |

解析层还发现 5 组同源弱重复和 8 组跨来源待审核关联，其中跨来源候选包括银行与微信、银行与支付宝。它们只作为候选，不得在用户确认前自动写入正式账本。

## 3. 业务规则

### 3.1 来源与统一账本

- 每条原始来源记录永久保留在当前家庭范围内，原始文件保留一年。
- 已确认 `duplicate` 关系的记录组成一个统一账本组件。
- 组件内优先选择银行来源作为 `primary_source_record_id`；如果已有正式账本锚点，优先复用已有锚点，避免重复导入再次生成交易。
- 支付宝、微信和记账 App 记录不丢弃，作为同一统一账单的详细来源记录展示。
- 没有关联候选的来源记录按独立账单进入统一账本。
- `parent_settlement`、`refund_reversal`、`fee_related`、`split` 和 `unrelated` 在本切片先保留为关系，不按 `duplicate` 折叠；每种关系的专项会计处理另立切片。

### 3.2 提交与幂等

- 批次必须处于 `confirmed`，仍有 `pending_review` 时禁止提交。
- 提交前校验批次版本和确认摘要哈希；版本不一致返回冲突，不覆盖用户最新选择。
- 同一个批次只能提交一次；重复提交返回零新增交易，不重复写账。
- 批次撤销只将该批次生成的正式账本交易标记为 `voided`，不删除原始文件、来源记录或关联关系。

## 4. 移动端页面骨架

1. **导入入口**：来源选择、文件选择、文件名称/大小/保留期限、解析中状态。
2. **表头确认**：Sheet 切换、批次级原始行预览、可见行号和单元格内容、系统高亮表头、点击行调整表头与数据起始行、表头不在第一行的提示。
3. **字段映射**：交易时间、收支方向、金额、商户、分类、流水号、渠道、备注；必填字段缺失时不可继续。
4. **关联审核**：候选两列卡片、匹配理由、置信度、关系选择；确认后显示待提交数量。
5. **提交预览**：银行锚点数、平台详情数、独立交易数、待处理数；点击每个数字进入对应账单列表。
6. **完成/撤销**：提交成功、部分异常、重试、撤销、保留期限提示。

所有页面遵循统一淡粉淡紫 Liquid Glass 设计系统：44pt 触控目标、4pt 间距网格、自适应容器、长文件名和长字段折行、减少动态效果设置可用。

## 5. API 与数据契约

复用当前已声明并已注册的导入状态机路径：

- `POST/GET /api/finance/import-batches`
- `POST /header-confirmation`
- `POST /mapping-confirmation`
- `GET/POST /reconciliation`
- `POST /commit`
- `POST /revoke`

本切片新增 `import_batch.header_preview`，与现有 `import_batch`、`import_row`、`source_record`、`reconciliation_group`、`transaction_link` 和 `ledger_transaction` 一起使用。解析 worker 只返回受限预览和规范化结果，由 API 在家庭事务中写入；实现重点是让 `commit` 真正消费已确认的 `duplicate` 关系，而不是只记录关系后仍逐条入账。

实现约束：当前 `LocalImportObjectStore` 只用于开发和测试；生产必须注入腾讯云 COS 私有桶适配器，不能把本地磁盘作为生产原始账单存储。

## 7. 本切片明确不做

- 不在首期接入银行 OAuth、支付平台登录或自动拉取；首期处理用户导出的文件。
- 不把“相似”直接视为“重复”；低置信度候选必须由用户审核。
- 不在本切片内决定退款、手续费、拆分和结算的完整会计分录规则。
- 不把原始账单内容上传到第三方 AI；解析和关联在受控服务内完成。
