# Life B-007/B-008 家庭邀请与成员角色垂直切片卡 v0.1

更新时间：2026-08-27

## 1. 目标与产品边界

本切片完成“家庭所有者邀请一位新成员 → 新账号加入当前唯一家庭 → 全体成员查看成员列表 → 所有者调整非所有者角色”的移动端闭环。

已确认且实现的边界：

- 一个账号只能属于一个家庭，不支持多家庭加入、默认家庭或家庭切换。
- 邀请码一次性使用，只允许加入为成人、儿童或访客；不能通过邀请码授予所有者。
- 所有成员可查看当前家庭成员；只有家庭所有者可创建/撤销邀请和修改角色。
- 角色变更会撤销该成员既有的显式财务授权，避免旧角色权限被意外继承；后续由所有者按需重新授权。
- 不建设轮询刷新。成员和邀请仅在进入页面及用户完成创建、撤销、改角色后确定性更新。

本切片关闭仓库级 `B-007`、`B-008`；目标腾讯云的原生 PostgreSQL、HTTPS Secure Cookie 和多实例共享限流仍由 `B-011`、`G-004` 与部署闸门验收。

## 2. 用户流程与 UI/UX

### 2.1 加入家庭

1. 所有者从“更多 → 家庭与成员”创建一次性邀请。
2. 所有者选择成人/儿童/访客和 1/7/30 天有效期。
3. 原始邀请码仅在创建成功层展示一次，可复制包含 `invite_token` 的链接。
4. 被邀请者打开链接后先看到家庭名称、邀请者和预分配角色，再填写新邮箱与密码。
5. 用户明确确认唯一家庭规则后注册并进入同一家庭。
6. 过期、撤销、已使用和已属于家庭均显示可恢复的明确错误。

### 2.2 成员与角色

- “家庭与成员”是“更多”的二级页面，不新增一级导航。
- 成员卡展示邮箱、角色、加入时间和当前账号标记；长邮箱在窄屏自动省略。
- 所有者点击非所有者角色按钮后进入确认层，角色变更前明确提示财务授权会被重置。
- 儿童和访客不显示邀请或角色编辑动作，只显示权限说明。
- 页面沿用淡粉淡紫环境、近白实体卡、44pt 最小命中区和 Liquid Glass Bottom Sheet。

## 3. 数据库与安全契约

迁移：`db/migrations/0012_household_invitations.sql`

- 新增 `household_invitation`，原始邀请码不写入数据库，仅保存 SHA-256 摘要。
- 邀请包含家庭、创建者、预分配角色、过期、接受和撤销状态；数据库限制角色只能为 `adult/child/guest`。
- 接受邀请在 `life_auth_accept_household_invitation` 中锁定邀请并原子创建用户、成员关系及消费状态。
- `household_member.user_id UNIQUE` 与受控接受函数共同保证一个账号不能加入第二个家庭。
- `life_family_create_invitation`、`life_family_revoke_invitation` 和 `life_family_update_member_role` 在数据库层再次验证所有者身份。
- 直接以应用角色修改成员关系由触发器拒绝，防止遗漏 API 校验时发生权限提升。
- 成员列表通过窄权限函数返回当前家庭邮箱，不开放全局 `app_user` 查询。
- 创建、撤销邀请和角色变更写入 `audit_log`；角色变化同时撤销现有显式财务授权。

## 4. API 契约

新增接口：

- `GET /api/auth/invitations/preview`
- `POST /api/auth/invitations/accept`
- `GET /api/family/members`
- `GET /api/family/invitations`
- `POST /api/family/invitations`
- `DELETE /api/family/invitations/{invitationId}`
- `PATCH /api/family/members/{userId}/role`

邀请预览和接受按令牌/邮箱与 IP 哈希键执行基础限流，返回 429 和 `Retry-After`。创建响应中的 `invite_code` 只返回一次，后续邀请列表不返回原始值。

OpenAPI：57 paths、79 schemas。

## 5. 状态矩阵

| 状态 | 移动端反馈 | 服务端结果 |
|---|---|---|
| 邀请有效 | 展示家庭、邀请者、角色和注册表单 | 可接受一次 |
| 邀请过期 | 明确联系所有者重新生成 | `410 INVITATION_EXPIRED` |
| 邀请撤销 | 明确邀请已撤销 | `410 INVITATION_REVOKED` |
| 邀请已使用 | 明确一次性邀请已消费 | `409 INVITATION_USED` |
| 邮箱已注册 | 说明账号已有家庭，不能加入第二家庭 | `409 ACCOUNT_ALREADY_HAS_HOUSEHOLD` |
| 非所有者管理邀请/角色 | 页面不展示动作，接口仍拒绝 | `403 HOUSEHOLD_OWNER_REQUIRED` |
| 修改所有者角色 | 页面不展示动作，接口仍拒绝 | `409 OWNER_ROLE_LOCKED` |
